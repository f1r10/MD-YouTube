# MD-YouTube
Qovluqlar yaradılır 
1.
```
mkdir md-youtube
cd md-youtube
```
2. virtual mühit yaradılır
```
python3 -m venv venv
source venv/bin/activate
```
3. Python kitabxanasını quraşdır
```
pip install -U pip
pip install -U "yt-dlp[default]"
```
4.youtube.py faylı yarat
```
nano youtube.py
```
5.işə sal
```
python youtube.py X-oA2ZLVswE
```
